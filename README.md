# Sarthak Pruthi — Portfolio

A static portfolio website for a Senior Java Backend / Distributed Systems Engineer.

## Publish free with GitHub Pages
1. Create a new public GitHub repository, for example `portfolio`.
2. Upload `index.html` and `style.css` to the repository root.
3. In the repository, open Settings → Pages.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will provide the public portfolio URL.
